# security-homelab
Cybersecurity HomeLab using Kali Linux, VirtualBox and vulnerable machines for educational purposes.

Dette projekt dokumenterer mit HomeLab til undervisning i IT-sikkerhed.

## Formål

Formålet er at opbygge et sikkert, isoleret labmiljø til at lære:
- Kali Linux
- Netværk og NAT
- Vulnerability scanning
- Port scanning
- Grundlæggende penetration testing

## Miljø

- Oracle VirtualBox
- Kali Linux
- Matrix-Breakout: 2 Morpheus
- NAT Network: 10.0.2.0/24

## Sikkerhed

Alle scanninger og tests udføres kun mod virtuelle maskiner i mit eget HomeLab.
